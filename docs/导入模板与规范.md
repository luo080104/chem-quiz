# 导入模板与规范（把 Word/PDF 变成正式题库）

## 一、推荐流程

```powershell
# 0) 原件放进 data/source/ 并保留（不覆盖）

# 1a) .docx 直接用 Python 抽取（文本 + 图片）
python scripts/extract-docx.py "data\source\your.docx" "data\source\your.txt" --images "public\images\yourbank"

# 1b) .doc 先转 docx（需要本机 Word），再执行 1a
#     或直接导出文本（无图片通道）：
powershell -ExecutionPolicy Bypass -File scripts/extract-doc.ps1 -In "data\source\your.doc" -Out "data\source\your.txt"

# 2) 解析题目（自动识别“1.”“第1题”等原题号；无编号则顺序编号）
node scripts/parse-questions.mjs "data\source\your.txt" "data\raw\your.raw.json" yourbank

# 3) 写答案键（可从模板复制）
copy data\templates\answer-key.template.json data\answer-keys\your.json

# 4) 合并成应用题库（带图片）
node scripts/build-bank.mjs --raw data\raw\your.raw.json --answers data\answer-keys\your.json `
  --out public\questions\chem-bank.json --bankVersion 1 --bankId chem-250 `
  --imageManifest public\images\yourbank\manifest.json --imageBase images/yourbank/

# 5) 校验
node scripts/validate-bank.mjs public\questions\chem-bank.json data\reports
```

## 二、答案键格式

见 `data/templates/answer-key.template.json`：

```jsonc
{
  "bankLabel": "your-bank-label",
  "answers": {
    "1":  { "answer": ["B"],        "explanation": "..." },
    "2":  { "answer": ["A", "C"],   "explanation": "..." },   // 多选
    "3":  { "answer": [],           "explanation": "待核", "flag": "contested" }
  }
}
```

- `answer` 为答案键数组；**多选**用多个键，判分要求集合完全一致。
- 空数组 = 尚无答案（界面显示“待核”，不计对错）。
- `flag` 可选：`contested`（有争议）等，会写入题库 `reviewStatus`。

## 三、题库字段（应用读取的结构）

`public/questions/chem-bank.json` → `questions[]`：

| 字段 | 说明 |
|---|---|
| `id` | 稳定 ID（`CHEM-001`…），勿复用旧 ID |
| `version` | 题库版本 |
| `originalNumber` | **原题号**（优先来自原件编号） |
| `type` | `single` / `multiple` |
| `stem` | 题干（内联图片占位符 `U+0001`） |
| `stemImages` | 题干内联图片 URL 数组（按占位符顺序） |
| `options[].imageUrl` | 图片选项 URL |
| `answer` / `candidateAnswer` | 候选答案 |
| `reviewStatus` | `approved` / `pending` / `pending-image` / `contested` |
| `source` | 题目来源与答案来源 |

## 四、图片规范

- 由 `extract-docx.py --images` 抽取到 `public/images/<bank>/`，并生成 `manifest.json`。
- `build-bank.mjs` 按**文档顺序**把占位符 `U+0001` 映射到图片：每道题先题干、后选项。
- 复杂结构式优先用**经核对的图片**；不要用自动上下标去猜结构式。

## 五、对照手机 DeepSeek 答案

```powershell
node scripts/compare-answers.mjs `
  --a data\answer-keys\your.json `
  --b data\answer-keys\phone-deepseek.json `
  --bank public\questions\chem-bank.json `
  --labelA "本次AI" --labelB "手机DeepSeek" --out data\reports
```

产出 `data/reports/answer-compare.{json,txt}`：一致 / 分歧 / 仅一方有。
**一致不等于审定**；分歧项需老师/教材或独立复算裁决，不得擅自二选一。

## 六、换题库与旧记录

- 应用按 `bankId` 隔离记录：`bankId` 变化时，旧记录自动归档（`archivedBanks`），不会把旧题记录错配到新题。
- 同一 `bankId` 仅升 `version`（更正答案/加解析）时保留记录；旧模拟成绩带版本号，题库变化后逐题解析不可用会明确提示。
