大学化学刷题（手机网页版，200 题）
链接：https://luo080104.github.io/chem-quiz/

功能：顺序刷题 + 随机抽题仿真模拟（正计时）；每题有答案、解析、中文翻译和难词注释；错题本、模拟答题卡、成绩趋势、学习记录备份。

安卓装到桌面（像 App 一样用）：
1. 别用微信直接打开；在微信里点右上角“···”选“在浏览器打开”，或直接用 Chrome 打开上面的链接。
2. 等页面加载完，点右上角三个点菜单。
3. 选“添加到主屏幕”（有的显示“安装应用”），确认即可。
4. 桌面会出现图标，以后点图标就能用。

断网也能刷：先用图标在线打开一次（缓存几秒），再开飞行模式，仍能刷题看图。联网打开一次即更新题库。

进度是各人各自的：学习记录只存在自己手机浏览器里，互不影响，也不会上传。换手机或清浏览器数据会丢，可用“学习记录备份”导出/导入。

说明：答案目前是 AI 做的“候选/待核”，个别题（如命名、晶系选项）标注了争议，以老师/教材为准。
